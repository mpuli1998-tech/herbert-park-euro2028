HERBERT PARK HOTEL x EURO 2028 — "Celebrate Every Goal. & Experience Dublin."

HOW TO OPEN
Unzip the folder and double-click index.html. It opens in any modern browser
(Chrome, Safari, Edge, Firefox). Keep index.html, styles.css, script.js and the
assets folder together.

REPLACING PLACEHOLDERS
- Hero video: save your Google Flow film as  assets/videos/hero-football-hotel.mp4
  (no text in the video — the headline is HTML). Until then the poster image shows.
- Photography: replace the files in assets/images with official Herbert Park /
  licensed images, keeping the SAME file names. All current images are labelled
  placeholders.
- Logo: swap the text logo in index.html for assets/images/logo.png (comment marks the spot).
- Packages & inclusions: edit the PACKAGES list at the top of script.js.
- Team colours: edit / add to the TEAMS list at the top of script.js.
- Links marked data-placeholder-link (booking engine, map, socials, package pages,
  away-match page) are disabled — add the real URL and remove that attribute.
- Footer address / phone / email are placeholders.

Fonts (Playfair Display, DM Sans) load from Google Fonts when online; offline the
page falls back to Georgia / Helvetica.
